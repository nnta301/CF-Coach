# CF-Coach

CF-Coach is a personalized Codeforces problem recommender for competitive programmers.

## Sprint 1 goal

Given a Codeforces handle, return 10 unsolved problems using a transparent baseline based on rating proximity and under-practiced tags.

## Team workflow

- Work is planned and tracked through GitHub Issues.
- Every change is developed on a branch and merged through a reviewed pull request.
- Shared module interfaces are defined in [docs/contracts.md](docs/contracts.md).
- Current project foundation is in [PR #1](https://github.com/nnta301/CF-Coach/pull/1).
