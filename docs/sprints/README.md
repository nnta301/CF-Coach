# Sprint History

This directory preserves the outcome of every sprint. The GitHub Project board shows current work; these files record what actually happened after each sprint ends.

## Naming

Use `sprint-01.md`, `sprint-02.md`, and so on.

## End-of-sprint template

```md
# Sprint N — <short name>

## Goal
<One measurable outcome for this sprint.>

## Planned issues
- #...

## Completed
- #...

## Not completed / carried over
- #... — reason

## Evidence
- Pull requests:
- Demo/test results:
- Metrics (if applicable):

## Retrospective
### What went well
-

### What was blocked or difficult
-

### Change for the next sprint
-
```
